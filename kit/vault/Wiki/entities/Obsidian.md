# Obsidian

> Aplikasi catatan Markdown tempat vault ini dibuka dan dijelajahi, termasuk Graph View yang menampilkan backlink antarhalaman.

Terkait dengan: [[Obsidian Workflow]], [[Arsitektur AI]]

## Pemakaian di sini

- Vault adalah folder biasa berisi berkas `.md`, jadi agent bisa menulis langsung tanpa aplikasi terbuka.
- Link `[[Nama Halaman]]` dan alias di frontmatter dipakai untuk menyambungkan halaman. Aturan penulisannya di [[Obsidian Workflow]].
- Folder `.obsidian/` berisi pengaturan aplikasi dan tidak ditulis agent.
